## v0.1.0 - 2026-11-21

### Added
- Status bar with workspaces, clock, tray, and system indicators
- Control center for volume, brightness, Bluetooth, and power actions
- Fuzzy app launcher and password-store search
- Nix flake package and Home Manager module for install and enable
- IPC toggles for bar windows so Hyprland keybinds can open overlays
