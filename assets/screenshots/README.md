# Screenshots

Curated images for the project README. Prefer:

- `bar.png` — status bar (full width or cropped strip)
- `control-center.png` — control center overlay
- `apps.png` — app launcher
- `password-search.png` — password search (**redact any real secrets**)

Keep files reasonably sized (under ~1.5 MB each). After adding images, uncomment the screenshot block in the root `README.md`.
